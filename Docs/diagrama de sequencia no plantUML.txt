@startuml
title Diagrama de Sequência - Assistente de IA para Exportação (Sistema Fiep)

autonumber
hide footbox

actor "Usuário" as Usuario
participant "Assistente de IA" as Assistente
participant "Interpretador da Consulta" as Interpretador
participant "Gestor da Operação\n de Exportação" as Operacao
participant "Conhecimento do Domínio" as Dominio
participant "Mecanismo de Aplicabilidade" as Aplicabilidade
database "Base de Regras e Requisitos" as Base
participant "Verificador de Restrições" as Restricoes
participant "Consulta de Fontes\nNormativas" as Fontes

Usuario -> Assistente: Envia consulta em linguagem natural\n("Quero exportar peças automotivas para a Argentina.\nQuais documentos preciso?")
activate Assistente

Assistente -> Interpretador: Encaminha consulta
activate Interpretador
Interpretador -> Interpretador: Identifica intenção do usuário\n(consultar documentos necessários)
Interpretador -> Interpretador: Extrai produto e país de destino
Interpretador --> Assistente: Retorna intenção e dados identificados
deactivate Interpretador

Assistente -> Operacao: Solicita estruturação do contexto\n da operação de exportação
activate Operacao
Operacao -> Dominio: Relaciona produto, origem,\ndestino e características informadas
activate Dominio
Dominio --> Operacao: Retorna contexto da operação
deactivate Dominio
Operacao --> Assistente: Operação contextualizada
deactivate Operacao

alt Informações insuficientes para determinar os requisitos
    Assistente --> Usuario: Solicita os dados necessários\npara complementar a operação
    Usuario -> Assistente: Informa os dados solicitados
    Assistente -> Interpretador: Reinterpreta os dados complementares
    Interpretador --> Assistente: Retorna contexto atualizado
else Contexto suficiente
    Assistente -> Aplicabilidade: Envia contexto da operação
end

activate Aplicabilidade
Aplicabilidade -> Base: Consulta regras aduaneiras,\nrequisitos e documentação relacionada
activate Base
Base --> Aplicabilidade: Retorna regras e requisitos candidatos
deactivate Base

Aplicabilidade -> Dominio: Verifica correspondência entre\nproduto, destino e condições normativas
activate Dominio
Dominio --> Aplicabilidade: Retorna regras e requisitos aplicáveis
deactivate Dominio

Aplicabilidade -> Restricoes: Solicita verificação de restrições
activate Restricoes
Restricoes -> Dominio: Verifica restrições relacionadas\n ao produto, destino e operação
activate Dominio
Dominio --> Restricoes: Retorna restrições identificadas
deactivate Dominio
Restricoes --> Aplicabilidade: Resultado da verificação
deactivate Restricoes

Aplicabilidade --> Assistente: Requisitos, documentos e\nrestrições identificados
deactivate Aplicabilidade

Assistente -> Fontes: Solicita fontes normativas\nque fundamentam as regras e requisitos
activate Fontes
Fontes -> Base: Recupera referências normativas\ne informações de vigência
activate Base
Base --> Fontes: Retorna fontes e dados disponíveis
deactivate Base
Fontes --> Assistente: Retorna referências normativas
deactivate Fontes

alt Existe restrição ou condição especial
    Assistente -> Assistente: Prepara orientação destacando\nlimitações, autorizações ou análises necessárias
else Não foi identificada restrição impeditiva
    Assistente -> Assistente: Organiza documentos e requisitos\naplicáveis à operação
end

Assistente -> Assistente: Elabora resposta orientativa\ncom justificativas e fontes disponíveis
Assistente --> Usuario: Apresenta documentos necessários,\nrequisitos, restrições e fontes normativas
deactivate Assistente

@enduml
